# Skeleton-Based Fall Detection

## Overview

A real-time fall detection system that uses human pose estimation and machine learning techniques to identify fall events from video streams. The system extracts skeletal keypoints, analyzes posture patterns, and detects falls for safety monitoring applications.

## Features

- Human pose estimation
- Skeleton keypoint extraction
- Fall event detection
- Real-time video processing
- Safety monitoring for elderly care

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- Machine Learning
