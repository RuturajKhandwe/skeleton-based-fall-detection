# Skeleton-Based Fall Detection

## Overview

A real-time computer vision system that detects human falls using pose estimation and skeletal keypoint analysis. The project is designed for elderly safety monitoring and healthcare applications.

## Features

- Human pose estimation
- Skeleton tracking
- Fall event detection
- Real-time monitoring
- Visual alerts

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

```bash
pip install -r requirements.txt
python main.py
```

## Applications

- Elderly care monitoring
- Smart healthcare systems
- Home safety monitoring
- Surveillance systems
